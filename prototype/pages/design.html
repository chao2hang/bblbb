四条统一原则

任何新页面、新组件和视觉修复，都先用这四条做判断。

01
Token 优先

颜色、间距、字号、圆角、层级只从语义 Token 取值，禁止散落硬编码。

02
结构先于装饰

页面先满足信息层级、可达性和响应式，再添加视觉强化，不用装饰掩盖结构问题。

03
状态必须完整

每个交互至少考虑 normal、hover、focus、disabled；异步操作补充 loading 与 error。

04
移动端同等可用

小屏不是桌面缩小版：操作热区、信息优先级和表格收缩都要有明确方案。

组件一律通过 var(--color-*) 取色，禁止硬编码十六进制值；暗色主题由 html[data-theme="dark"] 自动映射。

排版 · 字体阶梯

六个字号 Token 自上而下递增，正文一律 --text-base。

--text-xsBadge、Tag、辅助标注 · 12px / 18px
--text-sm列表元信息、摘要 · 13px / 20px
--text-base界面正文、表单、按钮 · 14px / 22px
--text-md列表主标题、文章正文 · 16px / 26px
--text-lg详情 H2、卡片组标题 · 18px / 28px
--text-xl页面标题 · 20px / 30px
--text-2xl文章详情主标题 · 24px / 34px

字重只用 400 / 500 / 600：正文 / 列表标题与按钮 / 页面标题与强调；代码与 ID 使用 var(--font-family-mono)。

基础 Tokens · 圆角

控件与容器统一从 Token 取圆角，不直接写像素。chaos 主题下控件为 5px、容器为 6px，药丸形态固定使用 --radius-full。

--radius-sm
--radius-md
--radius-lg
--radius-xl
--radius-full

chaos 主题覆盖后：控件统一 5px（--radius-sm）、容器 6px（--radius-md）；--radius-full 仅限按钮／徽标等药丸形态。所有圆角必须引用 Token，禁止硬编码（依据 docs/DESIGN-TOKENS.md 硬规则）。

组件规范 · 按钮与表单

按钮为四种语义 × 三种尺寸；表单控件统一高 36px、圆角 --radius-sm，必须提供 focus / disabled / error 反馈。

组件规范 · Tag 与 StatusBadge

.tag-pill 用于话题标签（可点选），.sbadge 用于对象状态；两者语义不同，不要混用。

布局与响应式

页面骨架先按容器、主内容与侧栏拆分，再为移动端定义收缩策略；不要只靠缩放解决小屏问题。

桌面 ≥1024px容器最大 1200px，左右内边距 24px；主内容 ≤840px，侧栏 280–320px，间距 24px。
平板 768–1023px主内容优先，侧栏下移或折叠；表格可横向滚动，保持字段可读。
手机 ≤767px单列布局，左右内边距 16px；底部导航固定，操作热区最小 44×44px。
详情正文阅读列最大 740px；面包屑、标题、正文、回复按垂直阅读顺序排列。
<main class="page-container">
  <header class="page-head">标题 + 关键操作</header>
  <div class="content-grid">主内容 + 侧栏</div>
</main>

状态与无障碍

状态不是装饰：组件必须可感知、可操作、可恢复；错误信息要说明原因与下一步。

对象必须覆盖实现口径
交互控件normal · hover · active · focus · disabled焦点环使用 --color-focus-ring；禁用态降低透明度且不可点击。
异步操作loading · success · error保留控件宽度，使用 spinner；完成或失败给出 Toast/表单提示。
键盘操作Tab · Enter/Space · Esc焦点顺序与视觉顺序一致；弹层打开时焦点进入并在关闭后还原。
命中区域桌面 ≥32×32 · 移动 ≥44×44视觉图标可小于热区；图标按钮必须有 aria-label。
文字与图标对比度 · 替代文本正文对比度 ≥4.5:1；装饰图标 aria-hidden，功能图标配文字或标签。
