# 值班矩阵（M15-RUNBOOK-07）

> 维护人：platform/operations-security。
> 值班联系人、升级路径、维护窗口、审批人和演练频率在此登记；具体地址/电话
> 在部署环境的受控 secret 配置中，不进入本仓库。

## 1. 值班联系人（角色）

| 角色 | 职责 | 覆盖 |
|---|---|---|
| 值班 A | 一线：告警确认、Runbook 执行、状态通报 | 7×24（轮班表由运维排班系统维护） |
| 值班 B | 一线备份：A 不可达时接管 | 同上 |
| 运维负责人 | 二线：P0 决策、备份/恢复、存储域 | 值班时间 + 升级 |
| 发布负责人 | 二线：发布/迁移/回滚 | 工作时间 + 升级 |
| 安全负责人 | P0 安全事件决策、审计保全、密钥轮换批准 | 按安全事件响应 |
| 产品/法务 | 隐私请求、法律保留、停用审批 | 工作时间 + 升级 |

## 2. 升级路径

```text
告警 → 值班 A（≤5 分钟响应）
  ├─ 15 分钟未恢复 → 值班 B + 运维负责人
  ├─ 30 分钟 P0 → 运维负责人 + 安全负责人（按事件类型）
  └─ 60 分钟 P0 → 产品负责人 + 管理层通报
事件等级：
  P0 = 数据风险/大面积不可用/凭证泄漏 → 立即
  P1 = 单域故障（邮件/附件/慢写）→ ≤30 分钟升级
  P2 = 轻微延迟/容量 → 工作时段处理
```

## 3. 维护窗口

- 常规发布/迁移：**每周四 02:00–04:00（UTC）**，提前 24h 通告；
- 数据库/存储迁移、密钥轮换：**每月第一个周六 02:00–06:00（UTC）**；
- 紧急维护：任何时间，需值班 + 审批人确认，全程审计；
- 窗口内禁止非审批变更；变更必须可回滚或有恢复点（发布前备份）。

## 4. 审批人（变更/操作批准）

| 变更类型 | 审批人 |
|---|---|
| 常规发布（M15-UPGRADE 流程） | 发布负责人 |
| 数据库/迁移/回滚 | 运维负责人 + 发布负责人（双人） |
| 密钥轮换/Secret 操作 | 安全负责人 + 运维负责人（四眼） |
| 法律保留/注销/删除 | 法务/隐私负责人 |
| 可选能力启用/停用 | 产品负责人 + 运维负责人 |
| 备份恢复/切流 | 运维负责人 + 值班 A（双人核对） |
