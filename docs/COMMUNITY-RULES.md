# BBLBB 社区规则 v1

本规则说明参与社区讨论、发布内容和提出举报时的基本要求。注册用户需在注册前阅读并同意本版本。规则更新时，应展示新版本并在产品内告知用户。

## 参与讨论

- 尊重他人，不骚扰、威胁、羞辱或针对个人进行持续攻击。
- 发布内容应与所在板块相关；不同意见请围绕观点交流，不公开他人的私人信息。
- 请勿冒充他人、伪造身份或以误导方式传播信息。

## 发布内容

- 不得发布违法内容、恶意软件、诈骗、垃圾广告或侵犯他人著作权的材料。
- 分享图片、文字和链接时，应有权发布并尊重隐私、版权与适用法律。
- 不得以重复灌水、操纵互动或绕过访问限制的方式影响社区秩序。

## 举报与处理

- 发现可能违规的内容，可以使用举报功能说明原因；请勿滥用举报或披露他人隐私。
- 平台会结合内容、上下文和社区安全进行审核；可能采取提醒、限制互动、隐藏或移除内容等措施。
- 如对处理结果有异议，可通过平台提供的申诉渠道反馈。

> 本 v1 文本按 `docs/MODERATION.md` 的举报原因、内容操作与申诉流程整理，并依用户授权用于注册同意页面。若正式运营需补充具体内容边界或处罚细则，应在发布新版前完成运营与法务审核、变更版本并通知用户。
